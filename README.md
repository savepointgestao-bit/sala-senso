# Sala Senso (testes)

Portal do Senso para testes com psicólogas e pacientes. Site estático (HTML, CSS e JavaScript), sem servidor próprio.
Os dados ficam no Supabase do projeto Senso; este repositório só guarda as telas.

Endereço: https://savepointgestao-bit.github.io/sala-senso/

Ambiente de testes. Não use para dados reais de pacientes.
